# ♿ KayaAccess

**KayaAccess** is a Stellar-powered dApp designed to digitize and verify PWD ID cards in the Philippines, ensuring transparent aid distribution and instant merchant verification.

## 🚀 Deployment Info
* **Network:** Stellar Testnet
* **Contract ID:** `CANNROOD4KQLWKGKQ6FYPD2GSBGBORDNTXSMEPF7ZH37ALQFFOESYA5O`

## 💡 Core Features
* **ID Verification:** Instantly authenticate PWD IDs on-chain.
* **Aid Disbursement:** Transparently send XLM/USDC aid to verified wallets.
